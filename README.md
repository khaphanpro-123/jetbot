# JetBot AprilTag Lab

Phòng thực hành trực tuyến giúp học sinh lớp 11 tìm hiểu camera, AprilTag, hiệu chỉnh camera, nhận diện và điều hướng JetBot.

## Chức năng chính

- Hành trình học gồm 7 bài thực hành.
- Sổ tay trực quan dành cho học sinh và giáo viên.
- Mô phỏng nhận diện và điều hướng AprilTag.
- Thu số liệu mô phỏng và nhập số liệu từ JetBot thật.
- So sánh sai số, xuất CSV và in hoặc lưu PDF.
- Lưu tiến độ trên trình duyệt.

Website: https://jetbot-apriltag-simulator.vercel.app/

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở `http://localhost:3000` trong trình duyệt.
